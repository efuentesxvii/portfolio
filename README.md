## Running Locally

No build steps needed. Just open the file:

```bash
git clone https://github.com/efuentesxvii/portfolio.git
cd portfolio
open index.html
```

Or drag `index.html` into any browser.

---

## Deployment

This site is deployed via **GitHub Pages**. Any push to `main` automatically updates the live site.

To enable GitHub Pages on your own fork:
1. Go to **Settings → Pages**
2. Set source to `main` branch, `/ (root)`
3. Save — your site will be live at `https://efuentesxvii.github.io/portfolio`
